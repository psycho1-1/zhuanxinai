## 核对范围

通过 B 站公开视频元数据接口核对视频编号、分集 CID、时长、作者，以及付费和分享标记。所选视频查询时未标记付费、充电专属或禁止分享。没有逐段观看或进行真实浏览器播放验证；公开视频状态可能变化，不能把接口成功等同于实际播放成功。

线段视频的标题对应线段比较与运算，不能据此确认包含中点全部内容；角视频重点对应余角和补角。页面明确说明范围，并保留原有完整文字要点与例题，供补充学习。

## 维护与运行

- `lib/lesson-videos.ts`：集中保存每节课的视频信息。`bvid` 标识视频，`cid` 精确标识分集，`page` 是从 1 开始的分集序号。合集中的两节课必须使用各自的 CID。
- `components/video-lesson.tsx`：显示播放器、来源、时长和可展开的知识要点。切换知识点会重新挂载播放器，停止上一节视频。
- 添加知识点时，TypeScript 的 `Record<Lesson['id'], LessonVideo>` 会要求同步填写对应视频。
- 默认关闭自动播放和弹幕，参数按 [B 站官方播放器文档](https://player.bilibili.com/) 设置。实际播放和登录要求由来源站决定。
- 播放器下始终提供“在 B 站观看”和“重新加载”。学习掌握度仍由答题记录计算，打开或看完视频不会自动算作掌握。
- 在项目目录运行 `npm run dev`，然后打开终端显示的本地网址；运行方式和项目结构详见根目录 `README.md`。
