# AI 老师启用指南

接口和界面已实现，未配置密钥时明确显示“尚未启用”。2026-09-10 已配置线上密钥，并通过一次线上真实数学问答检查。密钥仅在忽略提交的本地配置和线上 secret 中保存。

## 你需要做的事

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)，注册并登录账户。
2. 在平台创建 API Key。API 按使用量计费，请在平台确认余额和最新价格；不需要为了本项目购买 ChatGPT 订阅。
3. 把项目的 `.dev.vars.example` 复制为同目录 `.dev.vars`，用文本编辑器将密钥填写在 `DEEPSEEK_API_KEY=` 后面。不要把密钥发到聊天、放进网页代码或截图。
4. 将 `AI_TUTOR_ENABLED=false` 改为 `AI_TUTOR_ENABLED=true`。模型默认 `deepseek-v4-flash`，以 [官方文档](https://api-docs.deepseek.com/) 的可用模型为准。
5. 保存后告诉 Codex：“本地密钥已配置，请测试并启用线上 AI”。本地密钥文件已被 Git 忽略；线上要另行设置为 Sites 的 secret，再发布，不能把密钥文件打包上线。

## 本地运行与检查

在项目目录运行 `npm run db:setup` 后运行 `npm run dev`。网站的 AI 老师位于练习区下方。
运行 `node --test tests/tutor.test.mjs` 检查请求校验、额度限制和模拟模型响应；这些检查不产生模型费用，不能代替真实调用测试。

## 关键代码

- `components/ai-tutor.tsx`：展示当前题目的对话，切题清空，失败保留草稿。模型回复作为纯文本渲染。
- `app/api/tutor/route.ts`：在服务器核对题目及学习身份，查询当前学习者的最近答案，限制请求大小。密钥只在服务器使用。
- `server/tutor.ts`：提示词、输入校验、固定 DeepSeek 接口和调用限额。模型不参与改分。
- `db/schema.ts` 的 `tutor_limits`：持久化调用计数，新增迁移不修改原有答题表。

## 调用与数据范围

默认每个匿名学习身份每分钟最多 3 次、每天最多 50 次，全站每天最多 500 次；日界线为北京时间零点。每次最多输出 700 tokens，模型等待最多 25 秒。限额是调用次数上限，不是人民币预算。2026-09-10 按用户要求提高每日限额，保留已有调用计数。

在调用前通过 SQLite 条件更新预留名额；失败也占名额，多个限额中任意一个未通过都不会请求模型。匿名身份可能被重置，全站上限仍然有效。没有自动重试付费请求。

只传当前题目、知识点、最近一次答题结果和最近两轮对话给 DeepSeek；不传整个错题本。对话不存入本网站数据库，刷新或切题会清空；供应商的数据处理按其条款执行。接口没有联网搜索、文件上传或改变学习记录的权限。

提示词要求循序引导，但不能保证模型永远不直接说出答案。正式面向学生启用前，应以真实账号验证数学回答质量。
